# Phonetic voice script (for an English-accent TTS voice)

Paste this into the TTS app instead of the normal script, one line per take, same order.
The video's subtitles still use the correct Indonesian text (voice/make-voice.py SCRIPT) — this file is only what the voice reads.

Rules used: c → ch · u → oo · i → ee · a → ah · weak e → uh · ai → ie/eye · acronyms spelled the Indonesian way
(SMK → Es Em Kah, PDF → Peh Deh Ef, HP → Hah Peh). English loan words (E-Learning, Dashboard, Excel, Word, browser,
file, deadline, Timer, platform, input, score, click) are left in English on purpose.
If your app reads the hyphens as pauses, delete the hyphens inside words (keep the syllables together).

```
Suh-lah-maht dah-tahng dee E-Learning, Es Em Kah Bahk-tee In-sah-nee. Sah-too roo-ahng buh-lah-jar oon-took goo-roo dahn sees-wah.
Dee-rahn-chahng khoo-soos oon-took goo-roo dahn sees-wah. Kee-tah moo-lie dah-ree see-see goo-roo.
Dashboard goo-roo muh-rahng-koom suh-moo-ah kuh-lahs.

Leh-waht meh-noo Dees-koo-see Kuh-lahs, goo-roo bee-sah muh-njah-wahb pur-tah-nyah-ahn sees-wah lahng-soong dee for-room, luhng-kahp duh-ngahn fee-toor bah-lah-sahn puh-sahn.
Fee-toor oong-goo-lahn: Rah-por Oh-toh-mah-tees.
Ah-toor boh-boht too-gahs, boh-boht koo-ees ee-koot muh-nyuh-soo-eye-kahn. Seem-pahn, dahn rah-por lahng-soong dee-hee-toong oo-lahng.
Hah-seel-nyah bee-sah dee-oon-dooh kuh Excel, tahn-pah input oo-lahng.
Suh-kah-rahng, mah-ree buh-rah-leeh kuh see-see sees-wah.

Click Lee-haht, dahn moh-dool Peh Deh Ef lahng-soong tahm-peel dee browser.
Doh-koo-mehn Word joo-gah bee-sah dee-bah-chah lahng-soong, tahn-pah pur-loo muh-ngoon-dooh.

Wahk-too bur-jah-lahn oh-toh-mah-tees, oo-roo-tahn soh-ahl dee-ah-chahk, dahn jah-wah-bahn tur-seem-pahn oh-toh-mah-tees. Soh-ahl yahng soo-dah dee-leh-wah-tee tee-dahk bee-sah dee-boo-kah lah-gee.

Too-gahs dee kur-tahs? Choo-koop foh-toh, pee-leeh suh-kah-lee-goos, lah-loo oo-bah jah-dee sah-too file Peh Deh Ef yahng rah-pee.
```
